패스트트랙 전달 방식 3가지

구매자 입장에서 하나씩 눌러 보세요.

① 드라이브 · 구매자 구글 계정에만 권한

구매자가 결제한 번호와 구글 이메일을 넣으면, 그 계정으로만 열리는 드라이브 링크를 메일로 받아요.

  • 체험: 메일함의 「패스트트랙 열람 안내 (테스트 2)」 링크
  • 장점: 링크가 퍼져도 다른 계정은 못 열어요
  • 단점: 구글 계정이 꼭 있어야 하고, 다른 계정으로 로그인돼 있으면 헤매요
메일 찾아 열기

② 결제 완료 → 내 번호가 새겨진 PDF 바로 받기

결제 직후 화면에서 바로 PDF를 받아요. 모든 쪽에 구매자 번호가 새겨져 있어서, 퍼지면 누가 퍼뜨렸는지 알 수 있어요.

  • 장점: 가장 간단, 폰에 저장돼서 언제든 봄
  • 단점: 파일 자체는 복사·공유가 가능(억제만 됨)
결제 완료 화면 보기

③ 우리 사이트에서 읽기 (번호 인증)

결제한 번호로 인증하면 사이트 안에서 바로 읽어요. 파일을 내려주지 않고, 읽던 쪽을 기억해요.

  • 장점: 파일이 안 퍼짐, 이어 읽기, 읽은 기록 확인 가능
  • 단점: 인터넷이 있어야 봄, 화면 캡처는 막을 수 없음
