# 야심한 남자 brand-guide

모든 랜딩·카드뉴스·쇼츠 문구·메일은 이 파일을 기준으로 만든다. (알렉스 CH03·CH04: 규칙은 한 번 박는다)

## 누구에게
- 20~30대 남성. 유튜브 「야심한남자」 시청자(구독 8.7만, 남성 89%).
- 상태: 연락·첫 만남까지는 가는데 '좋은 사람'으로 끝남. 뭘 고쳐야 할지 모름. 픽업·자극적인 기술에 지쳤거나 의심함.

## 우리가 약속하는 것
- 기술 몇 개가 아니라 남자의 기준(마인드)과 생활부터 바꿔, 만남이 이어지게 한다.
- 근거: 패스트트랙 1부(마인드·변화·여자 이해) + 2부(실전).

## 톤
- 형이 동생에게 솔직하게 말하는 톤. 존댓말(~합니다/~해요) 기본, 단정적이고 짧게.
- 불편한 진실을 먼저 말하고, 해결책을 바로 준다.
- 과장 금지: "100% 성공", "무조건", "여자를 조종" 같은 표현 쓰지 않음. 수치는 실제 근거가 있을 때만.
- 여성 비하·대상화 표현 금지.

## 금지
- 확인 안 된 후기·성과(예시 표시 없는 가짜 후기) 금지.
- '픽업 아티스트' 이미지 연상 단어(작업, 꼬시기 기술 등) 지양.

## 디자인
- 배경 #0e0f12(다크), 카드 #17191f, 본문 #f3f1ec, 보조 #a3a7b0.
- 포인트 컬러 하나: 골드 #d9b15f. 결제·신청 버튼만 레드 #e2483d.
- 폰트 Pretendard, 굵은 제목(900), 모바일 480px 폭 기준.

## 문구 고정값 (CTA)
- 무료자료: "먼저 보시고, 마음에 들면 그때 결정하세요."
- 패스트트랙: "혼자서 더 빠르게 바꾸고 싶다면"
- 쇼츠 끝: "고정 댓글에서 1분 진단부터 해보세요."

## 상품 사다리 (주언규식)
쇼츠(풀링) → 롱폼(키 콘텐츠) → 1분 연애 진단(check.html) → 무료 E-BOOK 신청(free.html) → 14일 순차 공개(my.html) + 패스트트랙 신청자 전용가 → 패스트트랙 판매 페이지(fasttrack.html, 99,000원 페이앱) → 장기코칭. (전화 상담 없음: 무료자료에서 결제까지 전화 없이 간다, 11/26 효원 결정)
