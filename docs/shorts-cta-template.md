# 야남 쇼츠 15초 4비트 템플릿 (알렉스 CH10 + 주언규 풀링)

쇼츠의 역할은 '판매'가 아니라 **다음 단계로 넘기기**: 롱폼 → 고정 댓글 → 무료 E-BOOK(free.html).
모든 쇼츠는 아래 4비트를 따른다. 문구 톤은 `brand-guide.md`.

| 비트 | 시간 | 할 일 | 예시 |
|---|---|---|---|
| 1. 문제 제기 | 0~3초 | 시청자의 고통을 한 문장으로 | "다들 괜찮은 사람이라는데, 왜 연애는 안 될까?" |
| 2. 해법 한 조각 | 3~9초 | 패스트트랙 개념 1개만 (다 주지 않기) | "여자는 같은 여성 성향의 남자에게 끌리지 않습니다. 맞춰주기만 하면 친구가 됩니다." |
| 3. 신뢰 | 9~12초 | 근거·경험 한 줄 | "저도 24살까지 모태솔로였습니다." |
| 4. 행동 유도 | 12~15초 | 고정 댓글로 보내기 (고정 문구) | "고정 댓글에서 무료 E-BOOK 먼저 받아보세요." |

## 고정 댓글 (매 영상 동일, src로 영상 구분)
```
👉 무료 E-BOOK 먼저 받아보세요: https://gydnjs6580-boop.github.io/yanam/free.html?src=shorts_YYMMDD
```
- `src` 값이 시트 '이벤트'·'신청자'에 남아, 어떤 쇼츠가 신청을 만들었는지 보인다.

## 소재 뽑는 법 (프롬프트를 손으로 쓰지 않기)
맥락 파일(`/mnt/project-files/alexhacker/yanam_context/context_part1.md`, `context_part2.md`)을 가진 Claude에게:
```
야심한남자 쇼츠 대본 5개를 만들어 줘.
- 근거: 패스트트랙 맥락 파일의 '고민·고통'과 '랜딩 카피용 문장'에서 하나씩 골라
- 형식: docs/shorts-cta-template.md의 4비트(문제 0~3초 / 해법 한 조각 3~9초 / 신뢰 9~12초 / 행동 12~15초)
- 톤: docs/brand-guide.md (과장·여성 비하·픽업 느낌 금지)
- 해법은 한 조각만. 전부 알려주지 말 것
- 각 대본 끝에 고정 댓글 문구(src=shorts_날짜) 포함
```

## 점검
- 4번 비트가 빠진 쇼츠는 올리지 않는다.
- 주 1회: src별 신청 수 상위 3개 쇼츠의 1번 비트(문제)를 다음 주 소재로 재사용.
